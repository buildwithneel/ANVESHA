# RailGuard AI — Computer Vision & ML Module

This is the standalone AI/ML and Computer Vision module for **RailGuard AI**.

## Responsibilities
- CCTV / Video processing (OpenCV)
- Object detection & tracking (YOLO + ByteTrack)
- Person counting & crowd density analysis
- Restricted-zone intrusion detection
- Worker safety / PPE non-compliance detection
- Event deduplication & risk scoring
- Dispatching lightweight JSON events to the backend (`POST /api/ai/detections`)

## Prerequisites
- Python 3.10+ installed
- Pip package manager

## Installation
Run the following command to install dependencies:
```bash
pip install -r requirements.txt
```
